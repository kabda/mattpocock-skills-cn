description: 依据高可信度的一手来源调查问题，并将发现记录为仓库中的 Markdown 文件。当用户希望研究某个主题、收集文档或 API 事实，或把阅读调查工作委派给后台 agent 时使用。
---

启动一个**后台 agent**开展研究，让它阅读时你可以继续工作。

它的任务：

1. 依据**一手来源**（官方文档、源代码、规格说明、第一方 API）调查问题，而不是依据对这些来源的二手解读。将每项断言追溯到对其负责的原始来源。
2. 将发现写入单个 Markdown 文件，为每项断言引用来源。
3. 保存到仓库已有的此类笔记存放位置；遵循现有约定，如果没有约定，就放在合理的位置并说明在哪里。
