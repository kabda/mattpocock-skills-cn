---
name: resolving-merge-conflicts
description: "需要解决正在进行的 git merge/rebase 冲突时使用。"
---

1. **查看当前 merge/rebase 状态。** 检查 Git 历史和冲突文件。

2. **寻找每项冲突的一手来源。** 深入理解每项改动为什么作出，以及原本的意图。阅读提交信息，查看 PR 和原始 issue／工单。

3. **解决每个 hunk。** 尽可能保留双方意图。不兼容时，选择符合本次合并所声明目标的一方，并记录取舍。**不要**发明新行为。始终解决冲突，绝不 `--abort`。

4. 查明项目的**自动检查**并运行，通常先类型检查，再测试，再格式化。修复合并造成的任何问题。

5. **完成 merge/rebase。** 将所有内容加入暂存区并提交。如果正在 rebase，继续变基流程，直到所有提交均完成变基。
