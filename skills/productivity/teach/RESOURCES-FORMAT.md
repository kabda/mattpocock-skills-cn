# RESOURCES.md 格式

`RESOURCES.md` 是为本主题精选的可信来源集。讲解知识应从这里获取，而非依赖参数知识猜测。智慧来自这里列出的社区。

<a id="structure"></a>

## 结构

```md
# {Topic} Resources

## Knowledge

- [书籍：Zatsiorsky 与 Kraemer 著 _The Science and Practice of Strength Training_](https://example.com)
  关于训练编排与适应的基础著作。用途：周期化、恢复、强度区间相关内容。
- [文章：Greg Nuckols（Stronger By Science）的 "How Much Should I Train?"](https://example.com)
  基于证据的训练量基准综述。用途：各肌群每周组数目标。

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  信息质量高的 subreddit，管理规则反对未经证实的健身传言。用途：训练计划评议、平台期排查。
- 本地：{gym name} 的周二力量课
  用途：力量动作的实时教练反馈。
```

<a id="rules"></a>

## 规则

- **只收录高可信来源。** 优先一手来源、公认专家、同行评审成果，以及管理严格的社区。如果资源是披着教育外衣的营销，就不要收录。
- **每条都加注释。** 三个月后，单独一个链接毫无用处。加一行说明覆盖什么、何时使用。
- **按 Knowledge / Wisdom 分组。** 与 [SKILL.md](./SKILL.md) 的理念对应。资源只出现在一组中也可以。
- **明确指出缺口。** 使命需要的某个领域没有优质资源时，写一个 `## Gaps` 章节列出缺失内容，推动未来搜索。
- **果断清理。** 发现资源错误、肤浅或偏离使命时，应删除，而非埋起来。五个精良来源胜过三十个平庸来源。
- **记录社区偏好。** 用户选择不加入社区时，在这里注明，避免未来会话反复提议。
