# 杂项

我保留但很少使用的工具，未在插件中正式收录。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：设置 Claude Code hooks，在执行前阻止危险 Git 命令（push、reset --hard、clean 等）。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：将测试文件中的 `as` 类型断言迁移到 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建包含章节、题目、解答和讲解的练习目录结构。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：设置包含 lint-staged、Prettier、类型检查和测试的 Husky pre-commit hooks。
